Product Backlog - Sprint 1 (ClubEvents)
Priority ID SMART User Story Acceptance Criteria Story Points
1 US-01 As a new user, I want to sign up, log in, and pick a role (student or organizer) in Sprint 1 so access is controlled. Login/signup works; unauthorized users cannot access organizer pages. 3
2 US-02 As an organizer, I want full CRUD on club events with validations in Sprint 1 so event info stays accurate. Valid events save; invalid/missing fields show errors. 5
3 US-03 As a student, I want to browse events and register or cancel in Sprint 1 so I can join events. Registration updates state; duplicate or full-capacity booking is blocked. 5
4 US-04 As an organizer, I want to view the attendance list for my event in Sprint 1 so I can track attendees. Only the event's organizer sees its registered list. 3
5 US-05 As a user/organizer, I want event/registration updates via AJAX without full page reload in Sprint 1. Page updates without a full reload. 5
